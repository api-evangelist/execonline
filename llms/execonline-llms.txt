# ExecOnline

> ExecOnline is a New York-based B2B leadership-development company that partners with top business schools to deliver executive education online at enterprise scale. Founded in 2012, it blends professor-led courses, coaching, cohort sessions and on-demand content into one connected learning journey, with an insights-and-reporting layer that ties learning outcomes to business goals.

**Important for agents and integrators: ExecOnline has no public API.** As of 2026-08-04 there is no developer portal, no API documentation, no OpenAPI/AsyncAPI/GraphQL contract, no MCP server, and no A2A agent card on any ExecOnline host. The learning platform is a credentialed, customer-only web application. Do not assume an API endpoint exists; contact ExecOnline directly for any programmatic or data-integration requirement.
